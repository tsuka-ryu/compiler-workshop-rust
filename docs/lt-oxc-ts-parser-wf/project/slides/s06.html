JS のパーサーは、たいてい再帰下降という作りです。文法の段ごとに関数があって、上の段は下の段を呼んで、結果が返ってくるのを待ちます。a < b > (c); も、文、式、二項演算、と js/ の関数を呼び降りていきます。 WF メモ: ブログ第1回「降下のはしご」の書き方 (関数 / ファイル:行 / 役割の3列、└ で入れ子) にそろえた。まだ出していない行は透明にして置いてあるので、はしごの枚で行の位置が動かない。

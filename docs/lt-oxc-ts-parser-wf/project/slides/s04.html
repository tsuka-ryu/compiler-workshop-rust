JS として読むと a < b > (c); も比較 (a < b) > (c)。どう見分ける? 境界はどこ?

パーサーは、レキサーが切ったトークンを読んで、AST という木にします。トークンは括弧以外まったく同じなのに、木はまったく違います。しかもこの a < b > (c);、JS として読むとただの比較です。パーサーはどうやって見分けているのか。JS と TS の境界はどこにあるのか。それを見ていきます。 WF メモ: 旧4枚目 (トークン) と旧5枚目 (AST) を1枚にまとめた。
